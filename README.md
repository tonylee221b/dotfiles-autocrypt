# Personal Dotfiles used at AUTOCRYPT

## Files explained

- `.tmux.conf` -> [TMUX](https://github.com/tmux/tmux) (Terminal Mulitplexer)
- `kitty` -> [Kitty](https://sw.kovidgoyal.net/kitty/) Terminal
- `nvim` -> [Neovim](https://neovim.io/)
- `presenterm` -> [Presenterm](https://mfontanini.github.io/presenterm/) (Terminal Presentation Tool)

1. Clone this repo

```bash
git clone https://github.com/tonylee221b/dotfiles-autocrypt.git
```

2. Move `.tmux.conf` file to `~/`

```bash
mv .tmux.conf ~
```

3. Move `kitty`, `nvim` and `presenterm` folders to `~/.config`

```bash
mv kitty nvim presenterm ~/.config
```

4. Open nvim and enjoy!
